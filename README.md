# 1級建築施工管理技士 第二次検定 Webアプリ

Safariで開いて使う学習Webアプリです。iPhoneでは「共有 → ホーム画面に追加」でアプリのように起動できます。

## iPhoneで使う
1. このフォルダをHTTPSで公開します（GitHub Pages等）。
2. iPhoneのSafariでURLを開きます。
3. 共有ボタン → 「ホーム画面に追加」。
4. ホーム画面の「二次検定対策」から起動。

## 内容
- 2016～2025年度
- 年度別 問題1～6
- 選択式／正誤／記述
- 学習記録はiPhoneのブラウザ内に保存
- 元資料にない正答は勝手に生成しない
